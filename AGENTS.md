# Project instructions

Use `kd40000-dot/heliboard-vietnamese` as the canonical GitHub repository for all future work on this HeliBoard Vietnamese project. `HeliBorg/HeliBoard` is upstream only.

Read `PROJECT.md` and `docs/vietnamese-telex.md` before editing. Preserve the ViKey attribution and licenses. Apply Telex only to Vietnamese; keep existing text, paste, gesture results, passwords and other languages working correctly.

Use JDK 21 for the Android 16 Robolectric tests. Run focused tests relevant to changes and build an APK when changing app behavior. Do not claim physical-device testing without an actual device result. Keep build outputs and credentials out of source control.

`.project-migration/telex.patch` is the original checkpoint, not the live source. Edit the checked-in source after import. Original upstream workflow files are retained under `docs/upstream-workflows/` for reference.
